# 여기였지 기능형 프로토타입

사진과 위치를 함께 저장하고 지도, 기억, 컬렉션에서 다시 확인하는 모바일 우선 PWA입니다.

## 확인 방법

가장 간단한 방법은 폴더에서 아래 명령을 실행하는 것입니다.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다. 같은 와이파이에 연결된 휴대폰에서는 PC의 내부 IP와 포트 8080으로 접속할 수 있습니다.

## 구현된 기능

- 지도형 장소 목록과 카테고리 필터
- 장소 검색
- 사진 선택 및 미리보기
- 현재 위치 가져오기
- 장소, 메모, 태그, 공개 범위 저장
- 기억 타임라인
- 컬렉션 생성 및 장소 분류
- 장소 상세, 공유, 삭제
- 브라우저 로컬 저장
- JSON 데이터 백업
- PWA 설치 지원

## 다음 개발 단계

이 프로토타입의 화면과 흐름을 확정한 뒤 React Native/Expo 앱, Node.js API, PostgreSQL/PostGIS, 이미지 스토리지로 전환합니다.
