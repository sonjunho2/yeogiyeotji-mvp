# 여기였지 개발 로드맵

## 완료

- 서비스 핵심 정의와 MVP 범위
- 정보 구조와 사용자 흐름
- Figma 흑백 와이어프레임
- Figma 고화질 UI 8개 화면
- 브라우저 기능형 PWA 프로토타입
- GitHub Pages 무료 공개 배포
- 실제 OpenStreetMap 지도와 장소 마커
- 현재 위치 표시와 지도 클릭 위치 선택
- 지도에서 선택한 위치를 장소 등록 화면으로 전달
- 장소 상세에서 외부 지도 열기와 위치 공유
- 사진 업로드 전 브라우저 자동 압축
- 입력 문자 수 제한과 사용자 입력 화면 출력 보호
- Expo/React Native 네이티브 소스
- Node.js 장소·컬렉션 MVP API
- 웹 프로토타입 Node API 연결 기반
- 회원가입·로그인 기본 구조
- 사용자별 장소·컬렉션 데이터 격리

## 현재 공개 테스트 범위

- 데이터는 각 브라우저의 LocalStorage에 저장
- 사진은 브라우저 저장 용량에 맞게 압축 후 저장
- GitHub Pages 데모에는 로그인과 기기 간 동기화가 적용되지 않음
- GitHub Pages에서는 Node.js API가 실행되지 않음
